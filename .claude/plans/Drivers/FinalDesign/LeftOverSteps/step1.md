# Step 1 — Finish the evidence program

## Purpose

Prove the model-dependent parts before building the production language reader or identity system.

Step 1 answers:

1. Can models extract complete, correct facts from real source text?
2. Can models safely decide when two business causes are the same?
3. Can the system retrieve the correct existing cause without dangerous merging?
4. Do text and machine-tagged filing facts produce the same identity?

A failed experiment produces evidence and stops the affected lane. It never directly authorizes a code fix.

## Boundary

Step 1 may:

* run the frozen experiments;
* build only the missing temporary experiment tools named below;
* use existing production code through read-only or no-write paths;
* read Neo4j where the approved experiment requires real data;
* save prompts, raw replies, decisions, scores and manifests;
* update the experiment board and budget ledger;
* create separately reviewed experiment commits.

Step 1 must not:

* build the production reader or identity system;
* change production behavior because an experiment failed;
* switch from the old format to the new format;
* write to Neo4j;
* activate any channel;
* use future information or hidden answers;
* silently change a sample, answer key, threshold, model or pass requirement;
* rerun a failed arm without a named correction and fresh answer sample.
