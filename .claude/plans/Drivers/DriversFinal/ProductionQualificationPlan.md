## Requirements and measurement

- Preserve all required content, meaningful order, headings, table/list/footnote relationships, picture occurrences and provenance; reconstruct using saved extracted pieces and assets alone. Keep original bytes, raw readings and failures.
- Aim for near-100% recall and precision, with useful automatic coverage near 99%. No sample guarantees universal perfection; measure rather than assume generic behavior or correctness.
- Production stays automatic. Source review here is release evaluation, not a required human/AI step for every production document.
- Keep code minimal, generic and organized: one existing owner per shared rule, pinned native APIs first, no source-specific strings/coordinates, duplicate parser/scorer, speculative abstraction or cosmetic rewrite. Reproduce demonstrated failures before fixing; retain previous working behavior and unused real controls.
- Run 1,000 distinct, fixed in-scope source files through the actual extraction/reconstruction caller on the final frozen candidate. Count every selected file, including missing, failed, incomplete and unstarted ones. One source file is not a whole multi-file filing or a browser state.
- Independently compare complete originals against reconstructed output. Automatic `OK` and saved-output verification are not source recall. Keep ordinary selections and challenges separate; private Test answers remain private.
- Use bounded milestones and the largest demonstrated shared causes first. Preserve first failures, publish reviewed named files, keep this plan concise, and report work progress every 15 minutes while active.
- HTML/XML and nonreading picture connections remain in scope. OCR/PDF reading, downstream work, deployment, deletion and Neo4j writes remain excluded.

Report three separate measures: **work completed**; **document disposition** (verified/incomplete/failed/unstarted, with unknown reasons); **source fidelity** (fully reviewed/no required issue found, issue found, unread). An incomplete-document fraction is not a missing-content fraction. State the sampled population, exposure and uncertainty with any estimate; do not call automatic verification measured precision/recall.
