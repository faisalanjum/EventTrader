## Goal
Remove doubt that the agreed picture-reading rule is right, on real SEC pictures of every kind, with a checker strong enough to catch wrong rows, single digits, signs, units and wording.

**Agreed rule (owner, Oct 5):** accept a page only when two readers wrote exactly the same content on the whole page.
- History: free tool A + B + Chandra read every picture → any 2 match → accept; else Sonnet (must match one) → else Opus (to be checked) → else Sonnet's reading tagged "unsure".
- Live: A + B → match → accept; else Sonnet, accepted if it matches A or B; else Sonnet's reading tagged "provisional"; overnight the history steps confirm or fix.

## Work order
1. **Stronger checker** (here). Compare rows, not bags: every answer row's tokens must appear together, in order, in one reader row. Count single digits, spaced minus signs and units; measure wording accuracy. Codex's 5 probes (swapped rows, single digit, spaced minus, unit, qualifier) must all be caught. Validate on the 50 exact-answer pages with Sonnet and free-tool outputs (here); then Chandra's (copied back from the Mac).
2. **Stratified real dataset** (here). A random, database-weighted slice plus deliberate hard cases. Every type covered, labels checked.
3. **One Mac message:** copy back the 50 + 13 old outputs; run Chandra on the new set overnight; copy results back.
4. **Here:** free tools on every picture; Sonnet on every Mac-set picture; Opus on the "unsure" ones.
5. **Analysis:** shares per step, accepted-but-wrong (audited by a third reader plus eye checks), per-type results, history vs live. Final report to the owner.
6. **Placement check (owner, Oct 5):** OCR text lands beside the correct picture in the correct report, keeps its labels (status, reader) and source link (accession, file, picture, position), and reaches the AI reader with nothing missing or duplicated. Uses the grader manifest's 732 occurrences (575 pictures): every occurrence filled exactly once, repeated pictures filled identically, block count = occurrence count.
